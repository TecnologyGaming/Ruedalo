# Guía de Contribución — Ruedalo CONTRIBUTING

¡Bienvenido al equipo de desarrollo del ecosistema tecnológico de movilidad de **Ruedalo**!

---

## 🚀 Flujo de Trabajo (Git Workflow)

1.  **Estructura de Ramas:**
    *   `main`: Rama de producción estable. Toda actualización a esta rama debe ser testeada, auditada y autorizada.
    *   `develop`: Rama de desarrollo donde se integran las características aprobadas.
    *   `feature/nombre-feature`: Rama para implementar nuevas funcionalidades o componentes visuales específicos.
2.  **Commits Semánticos (Conventional Commits):**
    *   `feat: ...` para nuevas características o componentes.
    *   `fix: ...` para corrección de bugs o ajustes menores.
    *   `docs: ...` para actualizaciones de documentación.
    *   `style: ...` para ajustes visuales que no alteren la lógica de código.
3.  **Revisión de Código:** Todo Pull Request hacia `develop` o `main` debe ser revisado y aprobado para garantizar la calidad del ecosistema.
